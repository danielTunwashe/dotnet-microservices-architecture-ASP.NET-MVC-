# dotnet-microservices-architecture-ASP.NET-MVC-
This project is a practical implementation of a full-stack microservices architecture built using .NET 8, based on the course “.NET Core Microservices - The Complete Guide (.NET 8 MVC)” on Udemy.  It demonstrates how to develop, deploy, and scale distributed services using modern development practices and tools.

**🔧 Technologies & Tools Used**
.NET 8 / ASP.NET Core Web API & MVC

Microservices Architecture

Ocelot API Gateway

RabbitMQ – Message Bus for async communication

Entity Framework Core – Database access

Docker & Docker Compose

AutoMapper

JWT Authentication & Authorization

Swagger / Postman – API testing

SQL Server, MongoDB (optional)

**📦 Microservices Built**
Catalog Service – Product listing and details

Basket Service – Shopping cart logic

Discount Service – Coupon code management

Order Service – Order placement and processing

Identity Service – User authentication and JWT token generation

API Gateway – Unified entry point using Ocelot

MVC Web App – ASP.NET Core frontend client

**💡 Key Concepts Practiced**
Building and consuming RESTful APIs

Clean Architecture & Layered Design

Service-to-service communication (HTTP & RabbitMQ)

Centralized error handling and logging

Authentication across multiple services

Containerization with Docker
